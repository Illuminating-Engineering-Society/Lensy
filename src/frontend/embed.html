Embed Lensy in the Vitrium portal

Client request DO076. Paste the snippet below into Portal Settings → Portal Header in Vitrium Security. Typing a question and pressing Search opens Lensy in a new tab with that query already run.

Preview

Opens lensy.ies.org/?q=… in a new tab.

HTML to paste

<!-- Lensy — IES Standards Assistant. Opens lensy.ies.org in a new tab. -->
<form action="https://lensy.ies.org/" method="get" target="_blank" rel="noopener"
      style="display:flex;gap:8px;align-items:center;max-width:520px;margin:0 auto;font-family:inherit;">
  <input type="text" name="q" placeholder="Type a topic or ask a question"
         aria-label="Search the IES Lighting Library with Lensy"
         style="flex:1 1 auto;min-width:0;padding:10px 14px;border:1px solid #D1D5DB;border-radius:10px;font-size:14px;color:#2C2C2C;background:#fff;">
  <button type="submit"
          style="flex:none;display:inline-flex;align-items:center;gap:6px;padding:10px 18px;border:0;border-radius:10px;background:#D8930F;color:#fff;font-size:14px;font-weight:700;cursor:pointer;">
    <svg width="14" height="14" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.5" aria-hidden="true">
      <path stroke-linecap="round" stroke-linejoin="round" d="M21 21l-6-6m2-5a7 7 0 11-14 0 7 7 0 0114 0z"/>
    </svg>
    Search
  </button>
</form>

Notes

No JavaScript. It is a plain GET form, so pressing Enter or the button both work, and it survives a CMS that strips <script> tags or event-handler attributes from a header field. Every style is inline for the same reason.

No iframe. Lensy sends frame-ancestors 'none', so it cannot be framed — embedding the search UI itself inside the portal is not possible, and would in any case put a second session boundary between the reader and their Library.

Sign-in is preserved. The query travels in the URL, and Lensy's sign-in gate carries the whole path and query through the round trip — so a reader who is not yet signed in lands on their results, not on an empty search box.

Staging. To point the widget at lensy-staging.ies.org, change the form's action; nothing else depends on the host.
